# Идеи по улучшению RepoPacker для работы с LLM

Здесь собраны предложения по новым функциям, которые сделают инструмент полезнее для работы с нейросетями (Claude, ChatGPT, Gemini).

---

## 1. 🧠 Управление контекстом (Smart Context)

Самая большая проблема с LLM — это ограничение контекста и "шум" от лишних файлов.

- [ ] **Интерактивное дерево выбора:**
  Сейчас пакуется либо всё, либо игнорируется по списку.
  *Предложение:* Сделать дерево файлов с галочками (Tree View). Пользователь сможет выбрать: *"Упакуй только папку `/src/auth` и `config.js`"*. Это киллер-фича для точечных задач.

- [ ] **Поддержка .repopackerignore:**
  Поддержка кастомного файла игнорирования в корне репозитория (по аналогии с `.gitignore`), чтобы настройки сохранялись между сессиями.

- [ ] **Сжатие/Минификация (опционально):**
  Чекбокс "Remove Comments/Whitespace". Для ситуаций, когда код огромный, и нужно сэкономить токены, жертвуя читаемостью (хотя для ревью кода это вредно, для понимания логики иногда полезно).

## 2. 📝 Промпт-инжиниринг (Pre-prompts)

Пользователь обычно не просто кидает код, а просит что-то сделать.

- [ ] **Библиотека шаблонов (Prompt Templates):**
  Выпадающий список перед кнопкой "Pack". При выборе добавляет инструкцию в начало генерируемого файла:
  - *Code Review* — "Проведи ревью этого кода, найди уязвимости и ошибки..."
  - *Write Documentation* — "Напиши README.md на основе этого кода..."
  - *Refactoring* — "Предложи улучшения архитектуры..."
  - *Custom* — поле для ввода своего текстового промпта.

## 3. ⚙️ Форматирование под разные модели

Разные модели лучше "едят" разные форматы.

- [ ] **Переключатель формата вывода:**
  - **XML (Claude style):** Текущий вариант `<file_content>` (лучше всего для Claude 3.5).
  - **Markdown Blocks:** Стандартные ` ```js ... ``` ` с заголовками (лучше для GPT-4o и Gemini).
  - **JSON:** Один большой JSON-объект (удобно для API-скриптов).

## 4. 📊 Аналитика и Токены

- [ ] **Визуализация контекста:**
  Прогресс-бар "Заполненность контекста" с метками популярных моделей:
  - `[||||||....] 32k (GPT-4)`
  - `[||........] 128k (Claude)`
  Показывает, влезает ли проект в "один заход".

- [ ] **Оценка стоимости:**
  Примерная цена запроса по API (например, "$0.15 за этот промпт в GPT-4o"), чтобы пользователи понимали "цену" своего репозитория.

## 5. 🚀 Интеграции (Client-side)

- [ ] **Прямая отправка:** Кнопка "Open in ChatGPT", которая копирует текст и открывает новую вкладку.
- [ ] **Кэширование настроек:** Сохранять выбранные папки и лимиты в `localStorage`, чтобы при перезагрузке страницы не настраивать заново.
