# RepoPacker 📦

**Превратите ваш GitHub-репозиторий в один Markdown-файл для LLM.**

RepoPacker — это локальный веб-инструмент без зависимостей, который конвертирует ZIP-архив или папку с вашим кодом в оптимизированный промпт для больших языковых моделей (LLM), таких как Claude 3.5 Sonnet, GPT-4o и Gemini 1.5.

![RepoPacker Screenshot](assets/og-image.png)

## 🚀 Зачем это нужно?

Копировать файлы в чат с нейросетью по одному — долго и неудобно. RepoPacker решает эту проблему, упаковывая всю кодовую базу в один структурированный файл:

- **Дерево проекта:** Помогает LLM понять иерархию папок.
- **XML-структура:** Использует теги `<file_content>` для четкого разделения контекста.
- **Экономия токенов:** Автоматически отфильтровывает бинарные файлы (изображения, PDF, exe) и служебные папки (`node_modules`, `.git`).
- **Разбиение на части:** Если проект слишком большой, инструмент автоматически разделит его на несколько частей под лимиты контекста (32k, 128k, 200k токенов).
- **Распаковка (Unpack):** Возможность восстановить проект обратно в ZIP из сгенерированного Markdown-файла.

## ✨ Возможности

- **Работает локально:** Весь процесс происходит в вашем браузере. Ваш код никуда не отправляется.
- **Приватность:** Использует библиотеку `JSZip` для обработки данных на клиенте.
- **Drag & Drop:** Просто перетащите папку или `.zip` файл.
- **Умная фильтрация:** Игнорирует мусорные файлы и папки.
- **Приятный интерфейс:** Современный дизайн, Тёмная тема 🌙 и поддержка Русского/Английского языков 🌐.
- **Навигация:** В сгенерированном файле создаются ссылки для быстрого перехода к коду файлов.

## 🛠️ Как использовать

1. Откройте [RepoPacker](https://repopacker.app/) (или запустите локально).
2. Перетащите папку проекта или ZIP-архив в окно **Pack**.
3. Скачайте готовый `context.md`.
4. Загрузите этот файл в чат с вашей любимой нейросетью.

*Для восстановления проекта воспользуйтесь вкладкой **Unpack**.*

## 💻 Локальный запуск

Так как это статическое веб-приложение, его можно запустить любым статическим сервером.

```bash
# Клонируйте репозиторий
git clone https://github.com/your-username/RepoPacker.git
cd RepoPacker

# Запустите с помощью npx (Node.js)
npx serve .

# ИЛИ с помощью Python
python3 -m http.server
```

Откройте `http://localhost:3000` в вашем браузере.
